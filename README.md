# SBA 928 – Enhancing Market Research with AI Prompt Engineering

## Project Overview
This project demonstrates prompt engineering and fine-tuning of the FLAN-T5-small language model for market research analysis using the Marketing Campaign dataset.

## Dataset
- Marketing Campaign Dataset

## Technologies
- Python
- Hugging Face Transformers
- FLAN-T5-small
- UV Package Manager
- Pandas

## Files
- prepare_data.py – prepares the training dataset
- train_flan.py – fine-tunes FLAN-T5-small
- compare_models.py – compares the base and fine-tuned models
- model_comparison.csv – evaluation results
- SBA 928 Report.pdf – final project report

## Results
The fine-tuned model generated more structured and relevant market research insights than the base model.
